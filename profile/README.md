## 📌 Featured Projects

### NoByte · CMS
NoByte is our modular CMS with a plugin system, built for fast workflows, easy content editing, and a UI that stays out of your way.

- Intuitive content management interface
- Plugins to extend functionality
- Great for projects that want more than “just WordPress”

### Laravel Error Logger
A Laravel logging package for forwarding errors and notifications across multiple channels.

### Laravel PayPal
A Laravel-friendly package for integrating PayPal into PHP applications.

### FileSanitizer
A PHP package for secure file upload sanitization with metadata stripping, archive scanning, and content inspection.
